# Zotero-jasminum-ai-outline

基于官方 [Jasminum v1.1.45](https://github.com/l0o0/jasminum/releases/tag/v1.1.45) 的非官方优化版。固定源码提交 `d3b1b3227b0e46aaf56585c5c09ff9e343152ce4`，保留官方目录识别、书籍元数据等功能，并移植本机定制界面。公开增量补丁可审查、可重建，未用官方文件整体覆盖定制工程。

发行版本 **v1.1.45-ai.5**，Zotero 内部版本 **1.1.45.5**。保留插件 ID `jasminum@linxzh.com`、模型、Base URL、认证方式与已有用户偏好；通过本仓库的空更新清单禁用自动更新，避免覆盖定制代码（Zotero 10 要求 manifest 保留有效的 `update_url` 字段）。旧 Release 和旧安装包保留。

## 安装与模式

从 [Releases](https://github.com/hhdkz123-creator/Zotero-jasminum-ai-outline/releases) 下载 XPI，在 Zotero → 工具 → 插件 → 从文件安装插件中安装。支持范围沿用上游清单（9.0.3～11.x）；本次实机验证为 Zotero 10.0.9/macOS，其他版本尚未逐一验证。

在 Zotero → 设置 → 茉莉花中选择：

- **智能节省模式（默认）**：检查已有大纲 → 本地目录解析和逐标题定位 → AI 目录优先 → 校准/抽样 → 必要时全文兜底。目录可信且跳转验证通过就结束，不将 297 页当作必须发送的目标。
- **完整识别全文大纲（全功能模式）**：每批最多 5 页，检查全部页面上的可见标题。用于需要目录没有列出的细节标题的文献。智能模式只承诺保留实际目录列出的层级，不会根据一级目录虚构二、三级标题。

修复启动恢复 PDF 早于插件事件注册时按钮缺失的问题，启动后会补初始化已有阅读器。

本机原有的 PDF 大纲侧栏 AI 按钮、常驻保存按钮、静默运行、旋转动画、暂停/继续、自动保存 PDF 与茉莉花大纲、自动识别开关和失败重试均已移植。正常运行不打开任务/核对窗口。失败时显示原因；识别失败后继续已缓存页面，保存失败优先重试保存，不重新付费识别。

已有非空大纲（PDF、茉莉花缓存或当前界面任一来源）会保留并停止重复识别；发现无效跳转则报告问题并保留原数据。此保护也适用于完整模式。如需对已有目录生成另一版本，请先在 PDF 副本中手动整理/移除已有大纲，避免意外覆盖。

缓存模式与设置不同时，侧栏会在进度下方显示独立的选择区。按钮文字保持横排，可整颗换行。选择后继续原有流程，避免丢弃旧缓存或悄悄改变识别目标。反向 MediaBox/CropBox 的有效 PDF 现在先归一化页面框再渲染，避免 `Invalid PDF page geometry`。

## 分级识别与跳转

1. **本地识别**：通过 Zotero 的 PDF worker/PDF.js 文本能力及 PDF 原生书签读取目录。识别“目录、目次、Contents、Table of Contents”，按编号或可靠缩进保留层级。本地可完整解析并逐个匹配标题时，AI 请求为 0。文本仅在内存中处理。
2. **AI 目录优先**：每批最多 5 页，先查前 15 页，必要时延伸到第 30 页；每批结束即检查目录是否已完整，不必等到第 15 页。请求同时提取正文标题和页脚页码，便于后续兜底复用。视觉识别提示支持扫描件、双栏、中英文、罗马页码，并排除页眉、页脚、图表清单等。
3. **页码校准**：优先在本地逐标题定位，直接处理罗马前言、正文、附录及页码重置。扫描件复用官方 `tocAgent.ts` 的独立页码体系投票，至少两个物理页面必须一致，阿拉伯正文校准排除目录之前重置的前言/序言页码，矛盾的正文偏移仍拒绝；目录后存在较长前置材料时，分批寻找校准点，最多检查目录后 30 页。绝不未经验证套用固定“+14”。
4. **抽样验证**：检查各页码体系的开头、中间、结尾；抽样点的页码和可识别标题必须吻合。文本可用时优先本地核对，仅必要时补发图片。定位标题时采用实际文字/视觉坐标；只有页码可信时链接到页面顶部，明确标记为页面级定位。
5. **全文兜底**：没有完整目录、目录不受支持、校准或抽样失败才进入全文识别。已有目录图片和抽样图片不重复发送。图像中没有的章节不会被生成。

本地路径采用保守解析：复杂换行、双栏拼接、重复标题或不可靠文字层会交给视觉路径，而不会把不确定结果当作成功。纯扫描文献的复杂重置/局部偏移若无法通过独立校准验证，将回退全文提取可见标题。

## 用量、暂停与隐私

- 状态行显示本地识别、目录识别、页码校准、抽样验证、全文识别、保存中、已暂停等状态，以及请求次数和图片页数；悬停可查看详细数字、比例和 token。完成/失败后仍可查看最近状态。
- 请求次数统计接口尝试，包含失败；图片累计页数包含失败重试，比例使用去重后的发送页数 / PDF 总页数。本地检查页数和 AI 图片页数可重叠，不能相加当作已处理的文献总页数。
- token 只累计接口实际返回的 `prompt_tokens/completion_tokens/total_tokens` 数值；缺少字段就显示未提供，不估算订阅扣费或 token。
- **默认单次任务上限 12 次请求**，可在设置调整。达到上限暂停，工具栏说明再次点击 AI 将明确增加一组设置额度，允许继续后续校准或全文识别；不自动循环追加。HTTP 504 或等待超时时，侧栏显示缩批状态，自动从 5 页缩到 2 页，必要时再缩到 1 页。单页超时最多自动重试一次。每次尝试都计入请求上限，成功页不会重发，完整模式继续检查全文。持续失败时在侧栏展开原因，可点 AI 恢复。桥接登录、额度及超时错误会显示安全的具体原因。
- 成功结果以 `jasminum-ai-cache.json` 保存在附件目录，含目录/标题/坐标、页码与计数，不保存图片、正文、API Key 或登录凭据；成功保存后仍保留缓存并更新 PDF 身份，另存仅含计数的 `jasminum-ai-usage.json`。PDF 文件摘要、大小和修改时间共同决定缓存是否有效。模式不同时先暂停，侧栏提供“续用缓存模式 / 改用当前设置”的选择；切换模式保留成功页面与用量，重新整理结果。
- 完整有效响应即使恰逢暂停也会缓存。网络在服务已处理但尚未返回时中断，客户端无法知道结果，该批重试仍可能产生费用。失败计数不会因重启被重置。
- 图片仅在必要的识别请求中发给用户已经配置的接口/桥接服务；不上传到 GitHub。模型和接口参数沿用现有配置。HTTP 异常不会将请求正文、认证头或原始服务响应写进日志。

## 保存、备份与恢复

AI 保存前核对开始识别时的 PDF 内容摘要/修改时间/大小，以及磁盘和界面大纲快照；PDF 写入 worker 在读取前及最终写入前再次检查文件状态。发现外部修改就停止保存。先创建附件目录下 `jasminum-ai-backups/<时间戳>-<随机值>.pdf` 和同名 `.json`，已有备份不会被覆盖。PDF 使用临时文件原子替换；sidecar 失败时仅在当前 PDF 仍是本次写入结果的情况下回滚，并保留备份。

需要手动恢复时先关闭该 PDF，选择同一代 `.pdf/.json` 备份恢复原 PDF 和附件的 `jasminum-outline.json`，再重新打开。备份包含原始文献及原大纲，只保存在本机，不自动删除；请按磁盘空间自行整理。跨两个文件的保存不是操作系统级事务；进程崩溃或断电、在最后检查与原子替换之间发生的极短竞争窗口，仍可能需要使用备份恢复。本插件不能对其他 PDF 编辑器施加全局写锁。

## 297 页文献的请求估算

以下假设每批最多 5 页、无失败/重试，目录和模型返回可靠；只统计本插件发起的请求，不等价于 GPT/Codex 订阅扣费单位。

| 识别路径 | AI 请求 | 图片页数 | 假设 |
| --- | ---: | ---: | --- |
| 已有有效大纲 / 本地目录逐标题定位成功 | 0 | 0 | 本地可核对全部目的地 |
| 目录在第 3 页、PDF 第 15 页为正文 1 | 5 | 20（6.7%） | 探测 1–5；补查 6–8、9–13、14–18；抽样 144、294，已发页不重发 |
| 目录在前 15 页、校准和验证另需两批 | 最多约 5 | 最多约 25（8.4%） | 3 批目录 + 1 批校准 + 1 批抽样；较长前置材料会增加批次 |
| 本次真实 297 页著作恢复 | **新增 1** | **新增 1（0.34%）** | 复用原 29 页成功响应；只发第 180 页，第 295 页本地核验；全任务累计含历史失败为 15 请求/70 图输入/35 去重发送页 |
| 无目录或校准失败进入全文 / 完整模式 | 通常 60 | 297（100%） | `ceil(297/5)=60`；缓存页面按批分布可能造成不足 5 页的小批，因此混合路径可略多于 60 次，但不重复成功图片 |

如果超时后缩为每批 2 页或 1 页，297 页无缓存全文理论请求数分别为 149 或 297，还需加失败尝试。默认 12 次上限会在长任务中暂停；上述 60 次总量需要用户明确追加额度或调高上限。目录延伸到第 30 页、多个页码体系、不确定抽样、失败请求都会增加次数，不能保证任何书固定只需 5 次。

## 构建与验证

```sh
git clone https://github.com/l0o0/jasminum.git jasminum-src
git -C jasminum-src checkout d3b1b3227b0e46aaf56585c5c09ff9e343152ce4
python3 patches/patch_smart_outline.py jasminum-src
python3 patches/patch_jasminum_release_metadata.py jasminum-src
cp build-support/pnpm-lock.yaml jasminum-src/pnpm-lock.yaml
(cd jasminum-src && pnpm install --frozen-lockfile)
python3 tests/run-tests.py jasminum-src
(cd jasminum-src && pnpm run build)
python3 tests/prepare-xpi.py jasminum-src/build/jasminum_1.1.45-ai.5.xpi Zotero-jasminum-ai-outline_v1.1.45-ai.5.xpi
```

CI 使用 Node.js 22、pnpm 9.15.1、锁定依赖。构建会执行 TypeScript 检查，XPI 再验证 ZIP 完整性、名称、版本、插件 ID 与禁用自动更新，生成 SHA256。已有 Release 会令发布步骤停止，不覆盖附件。

本版通过官方的 14 个 CJS 回归套件（相关 fixture 已适配新任务入口）与新增 32 项智能识别测试，覆盖完整/缺失目录、扫描件、三级层级、罗马/重置页码、全文降级、取消、中断、缓存恢复、额度、已有大纲保护、外部修改、保存失败回滚。原始静默/进度补丁脚本保留供历史审查；本版由 `smart-outline-v1.1.45.patch` 一次性移植相关定制。

此前另用真实文献副本和用户现有 `gpt-6.1-sol` 本地桥接做实机验证：297 页学术著作复用 29 页旧缓存，仅新增 1 次请求、1 张图片，54 条目录自动保存；逐条核对 PDF 书签目的页，并点击验证 PDF 第 180 页。已有 AI 目录只含一级、二级，不虚构三级。完整模式对真实 8 页反向页面框 PDF 发出两次请求（5+3 图），全文识别及自动保存通过；完整模式切换复用旧缓存的阶段未发新请求。测试代理阻止任何重复发送成功页面，实际无拦截。原接口未返回 token usage，因此没有 token 数值或扣费估算。

历史合成 PDF 实机测试覆盖本地 0 请求、三级书签、扫描路径、暂停/继续、重启恢复和设置持久化；这些测试的模型返回使用 fixture，见 `tests/native/`。真实文献和识别缓存只留在本机，不随源码公开。

限制：本地检查整本文字层可能较慢；扫描件准确性取决于所配置视觉模型；损坏/加密 PDF、不规则页码和跨页目录仍可能进入全文路径；抽样无法证明未抽中位置完全没有局部插页；签名、交互表单等复杂 PDF 经过上游 pdf-lib 重写的兼容性需用副本确认。官方支持版本范围内的其他 Zotero/系统组合尚需实机验收。
